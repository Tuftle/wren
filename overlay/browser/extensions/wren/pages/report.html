this is the one thing in wren that leaves your device, and only when you press send. it sends the site name and the date and time, nothing else: no address path, no page content, no account, no history. your connection reaches tuftle's server like it would any website's, so the server can see your ip address for that moment. tuftle does not save it, though its web host may keep ordinary server logs.

the report gets a random code. when the problem has been looked at, wren finds out by asking tuftle about that code only, and tells you the next time it is open.
